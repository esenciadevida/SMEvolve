# Purpose

This document defines the Search Engine Optimization (SEO) strategy for the SMEvolve website.

Its objective is to maximize organic visibility, attract qualified business leads, and establish SMEvolve as a trusted authority in digital solutions and software engineering.

All website pages, blog articles, service pages, and future content should align with this strategy.

---

# SEO Objectives

SEO should support the following business goals:

- Increase qualified organic traffic.
- Generate project enquiries.
- Improve search visibility.
- Build topical authority.
- Strengthen brand recognition.
- Support long-term lead generation.

---

# SEO Principles

SEO decisions should prioritize:

- User intent
- High-quality content
- Technical excellence
- Website performance
- Accessibility
- Helpful information

Content should always be written for people first and search engines second.

Each service page should target one primary keyword and several related secondary keywords.

Example:

Service:

Laravel Development

Primary Keyword:

Laravel Development Company Nigeria

Secondary Keywords:

- Laravel Web Development
- Laravel Developers
- Laravel Business Applications

---

# URL Structure

URLs should be:

- Short
- Descriptive
- Human-readable

Examples:

/services

/services/web-development

/services/laravel-development

/blog

/blog/how-to-build-a-business-website

Avoid unnecessary URL parameters where possible.

---

# Page Titles

Each page must have:

- A unique title
- Relevant keywords
- Natural wording

Recommended length:

50–60 characters.

---

# Meta Descriptions

Every page should include a unique meta description.

Recommended length:

140–160 characters.

Descriptions should encourage users to click without using misleading language.

---

# Heading Structure

Every page should contain:

One H1

Logical H2 sections

Supporting H3 headings where appropriate

Headings should reflect the content hierarchy.

---

# Internal Linking

Every page should link naturally to related pages.

Examples:

Service Pages

→ Related Services

→ Portfolio

→ Blog Articles

→ Contact Page

Blog Articles

→ Relevant Services

→ Quote Wizard

→ Related Articles

Internal links should help users continue their journey through the website.

---

# Image SEO

Every image should include:

- Descriptive filename
- Alternative text
- Optimized file size
- Appropriate dimensions

Avoid generic filenames such as:

image1.jpg

photo.png

---

# Structured Data

Implement Schema.org structured data where appropriate.

Recommended schema types include:

- Organization
- LocalBusiness
- ProfessionalService
- WebSite
- BreadcrumbList
- FAQPage
- BlogPosting
- Article

---

# XML Sitemap

Generate an XML sitemap including:

- Static pages
- Service pages
- Portfolio
- Blog posts

Exclude:

- Error pages
- Development routes

---

# Robots.txt

Allow indexing of public content.

Block unnecessary administrative paths.

---

# Content Quality

Content should:

- Demonstrate expertise.
- Be accurate.
- Remain easy to understand.
- Solve real business problems.

# Performance & Core Web Vitals

SEO depends on strong performance.

Target metrics include:

- Performance Score ≥ 90
- LCP < 2.5 seconds
- CLS < 0.1
- INP within Google's recommended thresholds
